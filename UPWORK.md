### What you get

A custom AI-powered CLI tool tailored to your repository, giving your team structured implementation plans, safer code changes, and automated checks — all from the terminal.

### Deliverables

1. **Custom CLI tool** — Built for your specific project structure and tech stack
2. **LLM provider integration** — Your choice of OpenAI, Anthropic, Ollama (local), or custom
3. **Project analysis commands** — Understand codebase structure before any changes
4. **Implementation plan generator** — Convert natural-language requests into step-by-step plans
5. **Safe file modification system** — Dry-run preview, diff output, backup before changes
6. **Test and lint runner** — Automated checks with clear pass/fail reporting
7. **PR draft generator** — Titles, descriptions, and checklists for pull requests
8. **Safety guards** — Protection for sensitive files, dangerous commands, and hardcoded secrets
9. **Documentation and README** — Setup instructions and usage guide
